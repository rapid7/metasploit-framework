<h2>1.17.4 / 2026-03-26</h2>
<p>Fixed:</p>
<ul>
<li>Fix union by-value ABI mismatch with float and double types on ARM64 and X86_64.

<h2>1.17.3 / 2025-12-29</h2>
<p>Fixed:</p>
<ul>
<li>Opt-in for MFA requirement explicitly. <a href="https://redirect.github.com/ffi/ffi/issues/1159">#1159</a></li>
<li>Fix type signature for FFI::AutoPointer#initialize, FFI::StructByReference#native_type and FFI::Struct#auto_ptr . <a href="https://redirect.github.com/ffi/ffi/issues/1158">#1158</a></li>
<li>Fix function signature of function_call in FFI trampoline. <a href="https://redirect.github.com/ffi/ffi/issues/1154">#1154</a>
It failed on <code>aarch64-mingw-ucrt</code>.</li>
<li>Add workaround for segmentation faults on <code>aarch64-mingw-ucrt</code>. <a href="https://redirect.github.com/ffi/ffi/issues/1154">#1154</a></li>
<li>Call super in <code>Library#freeze</code> . <a href="https://redirect.github.com/ffi/ffi/issues/1154">#1154</a></li>
<li>Deny duplication of AutoPointer per #dup and #clone . <a href="https://redirect.github.com/ffi/ffi/issues/1173">#1173</a>
They led to double free before.</li>
</ul>
<p>Added:</p>
<ul>
<li>Add binary gems for Ruby-4.0, now providing binary gems for Ruby-3.0 to 4.0.</li>
<li>Add msys2_mingw_dependencies for Windows Mingw for automatic installation of libffi. <a href="https://redirect.github.com/ffi/ffi/issues/1143">#1143</a></li>
<li>Mark callback dispatcher thread as fork safe for Puma. <a href="https://redirect.github.com/ffi/ffi/issues/1156">#1156</a></li>
<li>Add missing FFI::Platform module and LastError signatures. <a href="https://redirect.github.com/ffi/ffi/issues/1169">#1169</a></li>
</ul>
<p>Removed:</p>
<ul>
<li>Drop fat binary gems for Ruby &lt; 3.0</li>
<li>Remove <code>FFI::TypesGenerator</code> from distributed gems. <a href="https://redirect.github.com/ffi/ffi/issues/1164">#1164</a></li>
<li>Remove libffi build dir after install, safing some install space. <a href="https://redirect.github.com/ffi/ffi/issues/1157">#1157</a></li>
</ul>

</ul>
