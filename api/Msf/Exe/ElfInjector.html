Overview

Injects a forked payload into an ELF executable while preserving its original entry point.

Code-cave injection extends the file and memory sizes of an executable PT_LOAD into zero-filled, unallocated padding. The existing segment becomes writable because injected payloads may need writable memory. If no suitable cave exists, a PT_NULL or an unprotected PT_NOTE is replaced by a new RWX PT_LOAD. Segment and section handling follows the System V ABI program-loading rules: https://refspecs.linuxfoundation.org/elf/gabi4+/ch5.pheader.html

def initialize(template:, payload: ''.b)
  raise ArgumentError, 'template must be a String' unless template.is_a?(String)
  raise ArgumentError, 'payload must be a String' unless payload.is_a?(String)

  @template = template.b
  @payload = payload.b
  parse_header
  parse_program_headers
  parse_section_headers
rescue ELFTools::ELFError => e
  raise ArgumentError, e.message
end

def generate
  raise ArgumentError, 'ELF is already injected' if injected?
  raise ArgumentError, 'payload must not be empty' if @payload.empty?

  code_cave = find_code_cave
  return inject_code_cave(code_cave) if code_cave

  inject_new_segment
end
