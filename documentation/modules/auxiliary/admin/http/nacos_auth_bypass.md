## Vulnerable Application

This module exploits an authentication bypass vulnerability in Alibaba Nacos versions prior to 1.4.1
(CVE-2021-29441).

The vulnerability exists because Nacos trusts requests containing the `User-Agent: Nacos-Server` header without
verifying that the request originated from another trusted Nacos server. An unauthenticated attacker can abuse this
behavior to bypass authentication and perform privileged administrative actions.

This module supports the following operations:

- Enumerate users
- Create a new user
- Delete an existing user
- Update a user's password

The vulnerability was fixed in Nacos 1.4.1. Use the standard Metasploit `check` command to test a target without
performing an administrative action.

## Testing

A vulnerable Nacos 1.4.0 environment with authentication enabled can be started with Docker:

```
docker run --rm --name nacos-1.4.0 --env MODE=standalone \
  --env NACOS_AUTH_ENABLE=true --publish 8848:8848 nacos/nacos-server:1.4.0
```

The vulnerable Nacos instance will be available on port 8848.

**Successfully tested on**

- Alibaba Nacos 1.4.0

## Verification Steps

1. Start the vulnerable Nacos 1.4.0 container.
2. Start `msfconsole`.
3. `use auxiliary/admin/http/nacos_auth_bypass`
4. `set RHOSTS <target>`
5. `check`
6. `run`
7. The module should report that the target appears vulnerable and display its configured users.

To create a new user:

1. `set ACTION CREATE_USER`
2. `set NEW_USERNAME metasploit`
3. `set PASSWORD Password123!`
4. `run`

## Options

### NEW_USERNAME

The username to create when using the `CREATE_USER` action. A random username is generated by default.

### PASSWORD

Password used when creating a new user.

### USERNAME_TO_DELETE

The existing username to delete when using the `DELETE_USER` action.

### USERNAME

The existing username whose password will be changed when using the `UPDATE_PASSWORD` action.

### NEW_PASSWORD

New password assigned during the `UPDATE_PASSWORD` action.

### ACTION

The action to perform.

Supported values are:

- LIST_USERS
- CREATE_USER
- DELETE_USER
- UPDATE_PASSWORD

The default action is `LIST_USERS`.
